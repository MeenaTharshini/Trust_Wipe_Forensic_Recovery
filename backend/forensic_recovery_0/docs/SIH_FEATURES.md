# Enterprise & SIH Compliance Features

- **Automated Verification**: Scans drives post-wipe to confirm zero leftover header signatures.
- **Multi-Format Carving**: Reconstructs lost image, document, database, and archive binaries.
- **Chain of Custody Logs**: Generates ISO/IEC 27037 compliant forensic audit streams.
- **Entropy Inspection**: Distinguishes unallocated slack space from encrypted payloads.
- **Court-Ready Reports**: Exports verification certificates with SHA-256 signatures.
